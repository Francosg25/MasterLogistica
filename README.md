# MasterLogistica

Aplicación interna para control de embarques, provisiones y auditoría de facturación.

## Desarrollo progresivo

- Fase 1: diseño relacional y reglas de arrastre mensual.
- Fase 2 (en construcción): PostgreSQL, FastAPI, Docker, Alembic, Microsoft Entra ID, RBAC y endpoints base con aislamiento por Owner.
- Fases posteriores: Angular/Glassmorphism, Masters, cierres rolling, importación de facturas y conciliación.

El código de esta fase se incorpora mediante commits por bloque. Los datos operativos, documentos de proveedores, archivos `.env` y credenciales quedan fuera del repositorio.
